# Executive Sales & Profit Dashboard

## Overview
This repository contains a fully functional, interactive HTML dashboard that visualizes sales and profit data. The dashboard fetches live data directly from an Excel file, ensuring real-time updates and dynamic data representation. 

## Project Workflow
The architecture of this project was built using a highly efficient, no-code/low-code backend integration:
1. **Data Hosting:** The raw data is maintained in an Excel file and hosted on **Microsoft OneDrive**.
2. **API Conversion:** The OneDrive share link was connected to a **Sheet-to-API** service, converting the spreadsheet data into a live, accessible API endpoint.
3. **AI-Assisted Development:** The generated API link, along with detailed structural prompts, was provided to **Google Gemini**.
4. **Frontend Generation:** Gemini generated a 100% functional HTML, CSS, and JavaScript page that seamlessly fetches data from the API and renders the dashboard interface.

## Technologies Used
* **Frontend:** HTML, CSS, JavaScript
* **Data Storage:** Microsoft Excel, OneDrive
* **Backend / API:** Sheet to API (JSON)
* **AI Tool:** Google Gemini
